# Autonomous Vision-Guided Differential Drive Bot

A differential drive mobile robot developed in ROS2 Humble. The robot is
modeled in URDF/Xacro, visualized in RViz2, and uses a camera for vision
perception. It builds a map of its environment with SLAM and navigates
autonomously to goal points using the Nav2 stack.

## Features
- URDF/Xacro robot model with differential drive base and camera mount
- Camera-based perception
- SLAM for real-time mapping and localization
- Nav2 for path planning and obstacle avoidance
- Simulation in Gazebo and visualization in RViz2
